One image that sums up the world's news of Tuesday 17 November 2026: a drawn newspaper front page with a dot-matrix world map and twelve numbered stories — Ukraine's strike on the Crimea Bridge, tankers hitting mines in the Strait of Hormuz, Trump landing in Manila for the ASEAN summit, Nvidia's first earnings since Jensen Huang stepped down, the global Microsoft 365 outage, Japan scrambling jets over Russian aircraft, Western nations urging Israel to open Gaza crossings, 128 states debating a ban on lethal autonomous weapons in Geneva, the EU charging Temu over illegal goods, the COP31 draft calling time on fossil fuels, Ebola in DR Congo still not under control, and India winning the U19 Asia Cup in a last-ball thriller.

The entry program (`main.py`, Python standard library only) copies the committed `entry.png` byte-for-byte to `/output/entry.png` and verifies its size and signature, so every run writes identical bytes. The poster itself was drawn programmatically with `draw.py` (Pillow) — real rendered text, no generated-image garbling.

## Run it

```sh
python3 main.py
```
